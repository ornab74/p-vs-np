# Automatic Locality from `A_d` and Explicit Anchor Designs

## 1. Purpose

`WITNESS_TEMPLATE_LOCALITY_CALCULUS.md` identified monochromatic-anchor rectangles

```text
R_S = U_S x V_S
```

for the standard CLIQUE hard sets. Each anchor `S` is a vertex subset with `|S|>=2`,

```text
U_S = {K_B : S subseteq B},
V_S = {G(chi) : chi is constant on S}.
```

This note proves two positive results:

1. for every such family, the CLO overlap condition `A_d` automatically implies low union locality;
2. there are explicit polynomial-size anchor families satisfying `A_d` with constant `d`.

Therefore the purely combinatorial task of constructing many low-locality, bounded-overlap rectangles is solvable. The remaining obstruction is whether those rectangles can robustly represent the exceptional behavior of a small unrestricted circuit.

## 2. Hard distribution

Let

```text
U_{n,k} = {K_B : B subseteq [n], |B|=k}
```

with `B` uniform.

Let `q=k-1`. Let `V_{n,k}` be generated by a uniform coloring

```text
chi : [n] -> [q]
```

conditioned on being nonconstant, with an edge present exactly when its endpoints receive different colors.

Write

```text
D_{n,k}=D_U x D_V.
```

For an anchor `S` of size `s`, define

```text
p_U(S) = Pr_B[S subseteq B]
       = (k)_s/(n)_s,
```

and

```text
p_V(S) = Pr_chi[chi is constant on S]
       = (q^(n-s)-1)/(q^(n-1)-1).
```

The rectangle mass is

```text
mu_S=p_U(S)p_V(S).
```

## 3. Negative-side bound

For every `s>=2`,

```text
p_V(S) <= 1/q = 1/(k-1).
```

### Proof

Since `s>=2`,

```text
q^(n-s)-1 <= q^(n-2)-1.
```

Also,

```text
q(q^(n-2)-1)
= q^(n-1)-q
<= q^(n-1)-1.
```

Divide by `q(q^(n-1)-1)`.

The inequality is strict for `q>1`.

## 4. Positive mass budget from `A_d`

Let `F` be any finite family of anchors, not necessarily of the same size. For a positive clique vertex set `B`, define the load

```text
lambda_F(B)=|{S in F : S subseteq B}|.
```

Condition `A_d` is exactly

```text
lambda_F(B)<=d
```

for every `k`-set `B`.

Averaging over uniform `B` gives

```text
sum_{S in F} p_U(S)
= E_B[lambda_F(B)]
<= d.
```

This identity is exact and does not use a union bound.

## 5. Automatic-locality theorem

### Theorem

Let `F` be any family of anchors satisfying:

1. `|S|>=2` for every `S in F`;
2. condition `A_d` on the positive sides `U_S`.

Then the locality of the union of monochromatic-anchor rectangles satisfies

```text
mu(F)
= D_{n,k}(union_{S in F} R_S)
<= d/(k-1).
```

### Proof

By the union bound,

```text
mu(F)
<= sum_{S in F} p_U(S)p_V(S).
```

Using `p_V(S)<=1/(k-1)`,

```text
mu(F)
<= (1/(k-1)) sum_{S in F} p_U(S).
```

The positive mass budget gives `sum_S p_U(S)<=d`.

### Corollary

If

```text
k-1 >= 50d,
```

then

```text
mu(F)<=1/50.
```

Thus for monochromatic-anchor oracles, the known locality threshold follows automatically from `A_d` whenever `k` dominates `d`.

## 6. Refined size-stratified bound

Let

```text
F_s={S in F : |S|=s}.
```

Define

```text
d_s=max_{|B|=k}|{S in F_s : S subseteq B}|.
```

Then

```text
mu(F)
<= sum_{s>=2}
   d_s * (q^(n-s)-1)/(q^(n-1)-1).
```

Indeed,

```text
sum_{S in F_s}p_U(S)
=E_B[lambda_{F_s}(B)]
<= d_s.
```

Large anchors receive exponentially smaller negative-side weights.

## 7. Explicit disjoint-anchor construction

Fix an integer `d>=1` and choose

```text
s = floor(k/(d+1)) + 1.
```

Then

```text
s > k/(d+1).
```

Partition as much of `[n]` as possible into pairwise disjoint `s`-sets:

```text
S_1,...,S_r,
r=floor(n/s).
```

Let

```text
F_disj={S_1,...,S_r}.
```

### Proposition

`F_disj` satisfies `A_d`.

### Proof

A `k`-set containing `t` pairwise disjoint anchors contains at least `ts` vertices. Hence

```text
t <= floor(k/s).
```

Because `s>k/(d+1)`,

```text
floor(k/s)<=d.
```

Therefore every positive clique belongs to at most `d` positive sides.

## 8. Family size

The construction contains

```text
r=floor(n/s)
```

rectangles.

Since

```text
s <= k/(d+1)+1,
```

one has the lower estimate

```text
r >= floor(n/(k/(d+1)+1)).
```

For constant `d` and `k<=n^(1/4)`, this is `Omega(n^(3/4))` up to constant factors. Thus the family is polynomially large while maintaining constant positive overlap.

## 9. Locality of the explicit design

By the automatic-locality theorem,

```text
mu(F_disj)<=d/(k-1).
```

A sharper union bound is

```text
mu(F_disj)
<= r * [(k)_s/(n)_s]
     * [(q^(n-s)-1)/(q^(n-1)-1)].
```

Because `s` is a positive fraction of `k` when `d` is constant, this quantity is typically far smaller than `d/(k-1)`.

## 10. Exact combinatorial target now solved

The following problem has a complete positive answer:

> Construct polynomially many monochromatic-anchor rectangles with constant `A_d` overlap and locality below `1/50`.

Take constant `d`, choose `k>=50d+1`, and use the disjoint-anchor construction.

It yields:

```text
|F|=Theta(n/k),
A_d,
mu(F)<=d/(k-1)<=1/50.
```

## 11. What remains unresolved

The construction does not show that the oracle family has enough expressive power to simulate a small unrestricted circuit.

Its covered hard-pair set is

```text
E_F
= union_{S in F}
  {(K_B,G(chi)) : S subseteq B and chi is constant on S}.
```

Most hard pairs need not lie in `E_F`, and low locality requires that they do not.

The missing representation theorem must show that all pairs requiring oracle assistance lie inside such a low-mass set.

Equivalently, a successful circuit-to-CLO theorem must prove:

```text
exceptional pairs of the canonical circuit
subseteq E_F
```

for a polynomial anchor family satisfying `A_d`.

## 12. Robust correctness still separate

Even a perfect exceptional-pair cover is not enough by itself. The outer monotone circuit must be correct for every monotone oracle interpretation that is `1` on `U_S` and `0` on `V_S`.

Thus the remaining obligations are:

1. canonical circuit construction;
2. assignment of exceptional gates or paths to anchors;
3. coverage of every pair needing assistance;
4. robust correctness under arbitrary separating oracle values;
5. any extra positive-side condition required by the lower-bound theorem.

The set-family existence, overlap, and locality parts are no longer open for monochromatic-anchor rectangles.

## 13. Consequence for proof strategy

The next useful invariant is not merely the number of exceptional pairs. It is **anchorability**:

> Can every exceptional pair be assigned to one of polynomially many large vertex anchors, with at most `d` anchors contained in any positive clique?

This is a hard-distribution-specific structural property. Proving it for a canonical representation would activate the low-locality CLO endpoint.

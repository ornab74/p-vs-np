# Orientation Support versus Violation Mass

## 1. Purpose

This note isolates the exact quantitative gap between graph-edge resampling audits and sparse gate orientation.

A coordinate belongs to the minimal orientation support when there exists at least one decreasing edge in that coordinate. A random edge-flip audit measures the probability mass of decreasing edges. Existence and mass are different notions.

## 2. Directional violation mass

Let

```text
f : {0,1}^N -> {0,1}.
```

For coordinate `i`, sample a context

```text
z in {0,1}^{N-1}
```

uniformly, insert `0` or `1` in coordinate `i`, and write the resulting points as `z^(i,0)` and `z^(i,1)`.

Define the decreasing-edge mass

```text
nu_i(f) = Pr_z[f(z^(i,0))=1 and f(z^(i,1))=0].
```

Define the one-coordinate audit by choosing `i` uniformly from `[N]`, then choosing `z` uniformly, and rejecting exactly on a decreasing edge.

Its rejection probability is

```text
delta_edge(f) = (1/N) sum_i nu_i(f).
```

This identity is exact.

## 3. Minimal orientation support

Let `beta_min(f)` denote the unique minimal orientation vector, equivalently the set of coordinates on which `f` has at least one decreasing hypercube edge.

Then

```text
beta_min(f)_i = 1 iff nu_i(f) > 0.
```

Therefore

```text
supp(beta_min(f)) = {i : nu_i(f)>0}.
```

The audit controls the average magnitude of the positive numbers `nu_i`; orientation support counts how many of them are nonzero.

## 4. Exponentially hidden full support

Define the spike function

```text
s_N(x) = 1 iff x = 0^N.
```

For every coordinate `i`, the edge from `0^N` to `e_i` is decreasing:

```text
s_N(0^N)=1,
s_N(e_i)=0.
```

Hence

```text
beta_min(s_N)=1^N
```

and

```text
|supp(beta_min(s_N))|=N.
```

However, for each coordinate there is exactly one violating context among `2^(N-1)` contexts, so

```text
nu_i(s_N)=2^(-(N-1)).
```

Consequently

```text
delta_edge(s_N)=2^(-(N-1)).
```

Thus a function may have maximal orientation support while the natural random edge audit rejects with exponentially small probability.

## 5. Exact margin theorem

A support bound becomes possible only after adding a lower-mass promise.

### Theorem

Assume there is a number `tau>0` such that for every coordinate `i`,

```text
nu_i(f)=0 or nu_i(f)>=tau.
```

If

```text
delta_edge(f)<=delta,
```

then

```text
|supp(beta_min(f))| <= N delta / tau.
```

### Proof

Let `S=supp(beta_min(f))`. Every `i in S` has `nu_i(f)>=tau`, hence

```text
N delta
>= sum_i nu_i(f)
>= sum_{i in S} nu_i(f)
>= |S| tau.
```

Rearrange.

## 6. Sharpness

Without the margin `tau`, no nontrivial support bound follows from `delta_edge` alone. The spike function has

```text
|supp(beta_min)|=N
```

with

```text
delta_edge=2^(-(N-1)).
```

The smallest possible nonzero `nu_i` under the uniform context distribution is exactly `2^(-(N-1))`, so the generic margin theorem recovers only the trivial bound `|S|<=N`.

## 7. Consequence for graph-sensitive audits

A graph-edge audit that samples random edge coordinates and random surrounding graph contexts can prove small average decreasing-edge mass. It cannot prove:

- small orientation support;
- low incident-vertex support;
- few dense-orientation gates;
- low CLO locality;

unless it also establishes a structural anti-hiding statement such as:

```text
every oriented coordinate has violation mass at least tau,
```

or gives a polynomial hitting set that intersects every decreasing-edge set.

## 8. Required replacement theorem

A viable bridge must establish one of the following special properties for canonical gate functions produced from the layered language:

1. **Mass margin:** every oriented graph coordinate has inverse-polynomial decreasing-edge mass.
2. **Compressible witnesses:** all decreasing edges are generated by polynomially many templates.
3. **Vertex concentration:** decreasing coordinates are incident to few graph vertices.
4. **Rectangle structure:** decreasing positive-negative pairs admit a polynomial low-locality rectangle cover.

The existing BRC, SRC, SPA, and random edge-resampling identities do not supply any of these properties.

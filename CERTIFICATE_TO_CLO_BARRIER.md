# Certificate Subcubes versus CLO Rectangles

## 1. Purpose

`CERTIFICATE_MARGIN_ORIENTATION_THEOREM.md` proves that small two-sided certificate complexity prevents decreasing hypercube edges from being exponentially isolated under the uniform cube distribution.

This note asks whether those certificate subcubes directly yield a polynomial-size monotone circuit with local oracles (CLO) of small locality on the standard CLIQUE hard sets.

They do not, without two additional properties:

1. a compatible-certificate cover of the relevant positive-negative hard pairs;
2. a bound under the hard-pair distribution, not merely the uniform cube distribution.

The gap already appears for a single negated edge literal.

## 2. CLO locality recalled

Let

```text
U subseteq CLIQUE^{-1}(1),
V subseteq CLIQUE^{-1}(0)
```

be the positive and negative hard sets. A local oracle is assigned a rectangle

```text
U_j x V_j,
U_j subseteq U,
V_j subseteq V.
```

For a product distribution

```text
D = D_U x D_V
```

on `U x V`, the locality of a family of oracle rectangles is

```text
mu = D(union_j U_j x V_j).
```

The CLO must be pointwise correct for every monotone interpretation of each oracle that is `1` on `U_j` and `0` on `V_j`.

Thus three requirements are independent:

- polynomial circuit/oracle count;
- small union locality;
- robust correctness for every separating oracle interpretation.

## 3. Certificate rectangles

Let

```text
g : {0,1}^N -> {0,1}
```

be a gate function. Let `A` be a 1-certificate and `B` a 0-certificate.

If `A` and `B` are compatible except that they assign opposite values to some coordinate `i`, define

```text
U_A = {u in U : u extends A},
V_B = {v in V : v extends B}.
```

Then

```text
g(U_A)=1,
g(V_B)=0,
```

so

```text
U_A x V_B
```

is a valid positive-negative rectangle for the gate's value separation.

Call such a pair `(A,B)` a compatible certificate pair.

## 4. Rectangle-count bound

Assume

```text
C_1(g) <= c_1,
C_0(g) <= c_0,
c=c_0+c_1.
```

The number of partial assignments of size at most `r` is at most

```text
P(N,r) = sum_{j=0}^r 2^j binom(N,j).
```

Therefore the number of compatible certificate-pair rectangles is at most

```text
R <= P(N,c_1) P(N,c_0).
```

Using

```text
P(N,r) <= (2eN/r)^r
```

for `1<=r<=N`, one obtains the coarse bound

```text
R <= (2eN)^c.
```

Consequences:

- if `c=O(1)`, the complete family has polynomial size;
- if `c=O(log N)`, the generic bound is `N^{O(log N)}`, only quasipolynomial;
- logarithmic certificate complexity alone does not guarantee polynomially many rectangles.

A polynomial CLO therefore requires either constant certificate complexity or a polynomially enumerable subfamily covering all relevant hard pairs.

## 5. Compatible-cover condition

Define the reversed hard-pair set for gate `g` by

```text
D_g = {(u,v) in U x V : g(u)=1 and g(v)=0}.
```

A family of compatible certificate pairs `P_g` covers the gate when

```text
D_g subseteq union_{(A,B) in P_g} U_A x V_B.
```

Small certificates do not automatically imply such a polynomial cover.

For a fixed pair `(u,v) in D_g`, a minimum 1-certificate for `u` and a minimum 0-certificate for `v` may conflict on many coordinates. The compatibility argument from an adjacent decreasing cube edge does not apply to arbitrary hard pairs.

Thus local anti-monotonicity and hard-pair separation are different objects.

## 6. Uniform-cube mass does not control CLO locality

The directional mass

```text
nu_i(g)
```

is measured by a uniform random context in the Boolean cube.

CLO locality is measured by

```text
D_U x D_V
```

on structured CLIQUE positives and complete multipartite negatives.

There is no general domination relation between these measures. A certificate subcube may have inverse-polynomial cube measure but intersect nearly every hard pair, or intersect none.

## 7. Explicit barrier: one negated edge literal

Fix a graph edge

```text
e={a,b}
```

and consider

```text
g_e(G)=not x_e(G).
```

This gate has

```text
C_0(g_e)=1,
C_1(g_e)=1,
```

and its unique compatible certificate rectangle on the hard sets is

```text
U_e = {K_S in U_{n,k} : e is absent from K_S},
V_e = {G(chi) in V_{n,k} : e is present in G(chi)}.
```

Under the standard positive distribution, a uniformly random `k`-clique contains `e` exactly when both endpoints belong to its vertex set. Hence

```text
D_U(U_e)
= 1 - binom(n-2,k-2)/binom(n,k)
= 1 - k(k-1)/(n(n-1)).
```

For the standard negative distribution generated by a uniform coloring

```text
chi : [n] -> [k-1]
```

conditioned on using at least two colors, `e` is present exactly when `chi(a) != chi(b)`. Since different colors already imply a nonconstant coloring,

```text
D_V(V_e)
= (1 - 1/(k-1)) / (1 - (k-1)^(1-n)).
```

Therefore the rectangle locality is exactly

```text
mu_e
= (1 - k(k-1)/(n(n-1)))
  * ((k-2)/(k-1))
  / (1 - (k-1)^(1-n)).
```

For the lower-bound regime `5<=k<=n^(1/4)`, this quantity is bounded away from zero and tends to `1` as `k` grows while `k=o(n)`.

In particular, it is far above the `1/50` locality regime used by the known arbitrary-depth CLO lower bound.

Thus constant certificate complexity does not imply small CLO locality.

## 8. Robust-correctness obstruction

Even if compatible certificate rectangles cover `D_g`, replacing a nonmonotone gate by oracle variables is not automatically a valid CLO construction.

A CLO must compute the target function for every monotone oracle interpretation separating each assigned rectangle. Certificate rectangles guarantee only the forced values on their designated positive and negative subsets.

Outside those subsets, oracle values may vary adversarially. A circuit obtained by substituting oracle variables for negated signals may therefore change its output unless an additional monotone robustness invariant is proved.

This is the same reason generic dual-rail simulation does not immediately yield a useful low-locality CLO.

## 9. Exact conditional construction target

A certificate-based CLO theorem would require, for every exceptional gate `g`, a family

```text
P_g={(A_j,B_j)}_{j<=R_g}
```

such that:

1. `R_g` is polynomial;
2. each `(A_j,B_j)` is a compatible 1/0-certificate pair;
3. the resulting rectangles cover every hard pair on which the monotone simulation needs help;
4. the union over all gates has hard-pair measure at most `mu`;
5. the outer monotone circuit is correct for every separating interpretation of all oracle variables;
6. the positive sides satisfy the required `A_d` overlap condition, if invoking the known arbitrary-depth lower bound.

Certificate complexity alone proves none of items 3--6.

## 10. New status

The certificate-margin theorem successfully solves the local anti-hiding problem under the uniform cube measure.

It does not solve the CLO bridge. The remaining missing theorem is now:

```text
canonical gate certificates
=>
polynomial compatible hard-pair rectangle cover
with low D_{n,k}-locality,
robust CLO correctness,
and bounded positive-side overlap.
```

The negated-edge example shows that this implication cannot follow from certificate size alone.

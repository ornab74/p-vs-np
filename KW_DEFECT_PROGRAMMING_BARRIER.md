# KW Defect Programming and the Large-Anchor Barrier

## 1. Purpose

The current CLO route asks whether a small representation-level Karchmer--Wigderson orientation defect forces reversed hard pairs to cluster inside a polynomial family of large monochromatic-anchor rectangles.

This implication is false for arbitrary equivalent representations.

A polynomial-size wrapper can preserve the computed function while programming the deterministic KW descent to create a reversed slice supported on one chosen positive clique. The added defect is exponentially small under the uniform positive hard distribution, but many pairs in that slice have no monochromatic anchor of size three or larger.

The result does not rule out a stronger canonicalization theorem. It proves that total orientation-defect mass alone cannot imply large-anchorability.

## 2. Hard sets

Let

```text
U_{n,k} = {K_B : B subseteq [n], |B|=k}
```

be the positive CLIQUE hard set.

Let `q=k-1`. Let `V_{n,k}` be the complete `q`-partite negative graphs generated by nonconstant colorings

```text
chi : [n] -> [q].
```

Use the product of the uniform distribution on `U_{n,k}` and the uniform distribution on nonconstant colorings.

Fix a distinguished `k`-set

```text
B_0 subseteq [n].
```

## 3. A selector with one positive zero

Let `H_{B_0}` be the graph whose edge set is

```text
E(H_{B_0})
= binom([n],2) \ binom(B_0,2).
```

Thus `H_{B_0}` contains every edge having at least one endpoint outside `B_0` and contains no edge entirely inside `B_0`.

Define the monotone selector

```text
A_{B_0}(G)
= OR_{e in E(H_{B_0})} x_e(G).
```

### Positive behavior

For a positive clique graph `K_B`,

```text
A_{B_0}(K_B)=0
```

if and only if `B=B_0`.

Indeed, `K_B` contains no `H_{B_0}` edge exactly when every pair of vertices of `B` lies inside `B_0`. Since both sets have size `k`, this means `B=B_0`.

### Negative behavior

Assume `n>k`. The graph `H_{B_0}` is connected: every vertex outside `B_0` is adjacent in `H_{B_0}` to every other vertex.

For a coloring graph `G(chi)`, an `H_{B_0}` edge is present exactly when its endpoints receive different colors. Therefore

```text
A_{B_0}(G(chi))=0
```

would force `chi` to be constant on every connected component of `H_{B_0}`, hence globally constant.

Since `V_{n,k}` excludes constant colorings,

```text
A_{B_0}(v)=1
```

for every `v in V_{n,k}`.

## 4. Function-preserving wrapper

Let `C` be any NNF circuit computing CLIQUE on the graph-edge variables. Define

```text
W_{B_0}(C)
=
(C AND A_{B_0})
OR
(C AND NOT A_{B_0}).
```

Push the complement of `A_{B_0}` to the leaves:

```text
NOT A_{B_0}
= AND_{e in E(H_{B_0})} NOT x_e.
```

Pointwise,

```text
W_{B_0}(C)=C.
```

The wrapper adds `O(n^2)` gates.

## 5. Deterministic descent order

Fix the following child order and deterministic rule:

1. at the top OR, Alice chooses the first child true on the positive input;
2. in each wrapper AND, the selector child is first and the copy of `C` is second;
3. inside `NOT A_{B_0}`, Bob chooses the first negated literal false on the negative input.

The ordinary KW `1/0` invariant is maintained throughout.

## 6. Exact programmed slice

### Distinguished positive input

Take

```text
u_0=K_{B_0}.
```

For every `v in V_{n,k}`,

```text
C(u_0)=1,
C(v)=0,
A_{B_0}(u_0)=0,
A_{B_0}(v)=1.
```

At the top OR, Alice is forced into

```text
C AND NOT A_{B_0}.
```

At that AND gate, both children are false on `v`, and the deterministic order sends Bob into `NOT A_{B_0}`.

Since `A_{B_0}(v)=1`, some edge `e in E(H_{B_0})` is present in `v`. Bob reaches a leaf

```text
NOT x_e
```

with

```text
u_0(e)=0,
v(e)=1.
```

Thus every pair in

```text
{u_0} x V_{n,k}
```

terminates at a reversed literal before entering `C`.

### Every other positive input

If `u=K_B` with `B!=B_0`, then

```text
A_{B_0}(u)=A_{B_0}(v)=1.
```

Alice enters `C AND A_{B_0}`. At that AND gate the selector is true on `v`, while `C(v)=0`, so Bob is forced into `C`.

Therefore the wrapper changes the descent only on the distinguished positive slice.

## 7. Defect accounting

Let `Rev_C` be the reversed-pair set of the original deterministic descent and `Rev_W` that of the wrapped circuit. Then

```text
Rev_W
= Rev_C union ({u_0} x V_{n,k}).
```

Consequently,

```text
defect(W_{B_0}(C))
<= defect(C) + 1/binom(n,k).
```

If the original descent is monotone on the hard pairs, then the wrapped defect is exactly

```text
1/binom(n,k).
```

Thus an exponentially small defect can contain a pointwise-obligatory reversed slice.

## 8. No large monochromatic anchor

Consider colorings whose restriction to `B_0` uses all `q=k-1` colors. Since `|B_0|=k`, exactly one color appears twice and every other color appears once.

For each such coloring,

```text
max_c |{b in B_0 : chi(b)=c}| = 2.
```

Therefore no set

```text
S subseteq B_0,
|S|>=3
```

is monochromatic.

The number of restrictions `chi|_{B_0}` with this property is

```text
binom(k,2) (k-1)!.
```

Every extension to `[n]` remains nonconstant. Hence their probability under the conditioned negative distribution is

```text
p_bal
=
binom(k,2) (k-1)! (k-1)^(n-k)
/
((k-1)^n-(k-1)).
```

This is strictly positive.

For all corresponding pairs `(u_0,v)`, the wrapper descent is reversed, but no monochromatic-anchor rectangle with anchor size at least three can contain the pair.

## 9. Failure of the proposed implication

For every anchor threshold `s>=3`, the implication

```text
small representation-level KW defect
=>
every reversed pair has a monochromatic anchor of size at least s
```

is false.

For the large-anchor regime

```text
s > k/(d+1),
```

this applies whenever

```text
k/(d+1) >= 2,
```

which includes constant `d` and sufficiently large `k`.

## 10. Why minimization does not erase the warning

The function-level quantity

```text
defect(f,size)
```

minimizes over equivalent circuits. The wrapper does not prove that every minimum-defect representation contains the programmed slice.

It proves a different and necessary point:

> A theorem whose only hypothesis is that a supplied representation has small total defect cannot conclude large-anchorability.

Such a theorem must impose a canonical descent, minimize a stronger anchor-aware objective, or explicitly clean up nonanchorable slices.

## 11. Cheap arbitrary-rectangle cleanup

The programmed slice itself has a simple non-anchor rectangle:

```text
{u_0} x V_{n,k}.
```

Its locality is exactly

```text
1/binom(n,k),
```

and its positive-side overlap contribution is one.

Thus the counterexample does not rule out general CLO cleanup. It rules out restricting all oracle rectangles to large monochromatic-anchor form.

This suggests a hybrid conversion:

1. large-anchor rectangles for structured bulk error;
2. a polynomial number of low-positive-mass cleanup rectangles for sparse exceptional positive inputs.

## 12. New invariant: positive projection complexity

For an exceptional set

```text
E subseteq U x V,
```

define its positive projection

```text
pi_U(E)={u in U : exists v, (u,v) in E}.
```

The wrapper has

```text
|pi_U(E)|=1
```

although its pairs are not large-anchorable.

A more viable structural theorem would bound a combination of:

- large-anchorable bulk locality;
- the cardinality or rectangle-cover complexity of the remaining positive projection;
- robust correctness of the resulting hybrid CLO.

Total defect mass alone controls none of these pointwise quantities.

## 13. Revised central target

Replace the false large-anchor implication by the following hybrid statement:

```text
Rev_C subseteq E_anchor union E_cleanup,
```

where:

1. `E_anchor` is covered by a polynomial `A_d` family of monochromatic-anchor rectangles;
2. `E_cleanup` has polynomial positive-projection complexity or a polynomial rectangle cover;
3. the union locality remains below the CLO threshold;
4. the monotone simulation is robust for every separating oracle interpretation.

This target survives the programmed-slice counterexample and is strictly more precise than total orientation defect.
